# FirstBite — Mapeamento de Concorrentes / Prior Art

Data de acesso: 2026-09-14. Ver `ECOSYSTEM.md` para o contexto completo sobre a Cookie Chain e a descoberta de que este projeto (FirstBite) muito provavelmente é uma submissão para o bounty do Superteam Earn **"Create an App on Cookie Chain"** (sponsor: Cookie Chain, prêmio US$ 1.000, 72 submissões registradas, vencedores anunciados em 28/09/2026 — fonte: https://superteam.fun/earn/listing/create-an-app-on-cookie-chain-app/).

**Aviso de método**: a lista abaixo cobre o que foi encontrado via busca web e GitHub API em 2026-09-14, incluindo os 15 Pull Requests visíveis no repositório oficial `cookiechain/superteam-hackathon-submissions` mais alguns achados adicionais de busca. **Isso NÃO é garantidamente a lista completa das 72 submissões do bounty** — a maioria (57 de 72) não tem PR visível nesse repo. Tratar esta tabela como uma amostra representativa, não exaustiva.

## Ecossistema Solana mais amplo (fora da Cookie Chain)

| Ferramenta | Categoria | Relevância para FirstBite |
|---|---|---|
| **Solana Pay / Blinks & Actions** | Padrão de link de ação on-chain compartilhável | FATO CONFIRMADO: Blinks transforma uma ação on-chain em link compartilhável que gera um prompt de assinatura direto de uma rede social. É a base conceitual de "link que vira transação" — mas o padrão em si não resolve zero-balance nativamente; foi feito majoritariamente para *pagamentos/ações* de quem já tem carteira financiada. |
| **Solana Developer Cookbook — Fee Sponsorship** (solana.com/developers/cookbook/transactions/fee-sponsorship) | Documentação oficial de padrão de patrocínio de taxa | FATO CONFIRMADO — a Solana oficial documenta o padrão "uma conta paga a taxa de outra" via `feePayer` alternativo na transação. É o mecanismo técnico de referência que o FirstBite usaria (adaptado à Cookie Chain, que é SVM-compatível). |
| **Blink Labs — Gas Sponsorship** (docs.blinklabs.xyz/blink/solana/gas-sponsorship) | Produto de infraestrutura de patrocínio de gas | FATO CONFIRMADO — existe como produto no ecossistema Solana mainnet, endereçando cenários muito parecidos com o do FirstBite: "users receiving airdropped tokens but having never held SOL", "CEX-to-Wallet onboarding". **Isso é o concorrente conceitual mais próximo do FirstBite, mas na Solana mainnet, não na Cookie Chain** — não encontrei evidência de que Blink Labs opere na Cookie Chain. |
| Faucets tradicionais de testnet (ex.: faucet.solana.com) | Distribuição de token de teste | Modelo mental próximo (dar token a quem não tem), mas sem componente de link/QR pessoa-a-pessoa nem de patrocínio de taxa de claim — é self-serve e limitado a redes de teste. |

## Conclusão sobre originalidade do FirstBite

Com base na pesquisa:

1. **Não foi encontrado, nem no registry oficial da Cookie Chain, nem entre as submissões de bounty mapeadas, nem no ecossistema Solana amplo, um produto que combine exatamente os três elementos do FirstBite**: (a) link/QR gerado por um holder de COOK, (b) reivindicável por um destinatário com 0 COOK, (c) com a taxa da transação de claim patrocinada automaticamente.
2. Os elementos individuais **já existem separadamente e têm prior art claro**:
   - Fee sponsorship on-chain: já implementado por **Arisan** dentro do próprio bounty, e documentado oficialmente pela Solana (Cookbook) e por produtos como Blink Labs no ecossistema mais amplo.
   - Link + QR code para transação: já implementado por **Cookie Tab** e **Sprinkle** dentro do próprio bounty (só que no sentido pagamento, não claim).
   - Distribuição para múltiplos destinatários / airdrop: já implementado por **Cookie Payouts** e **Crumbs** (modelo push, não pull).
   - Onboarding gamificado de novo usuário: **CookieForge** toca o tema, mas via XP, não via distribuição real de COOK.
3. **Risco real**: com 72 submissões e apenas ~18 mapeadas em detalhe aqui, é estatisticamente provável que existam 1–2 submissões adicionais não descobertas que combinem esses elementos de forma mais próxima ao FirstBite. Recomendo, antes de finalizar o pitch, uma segunda passada específica no repositório `cookiechain/superteam-hackathon-submissions` (e no board do Superteam Earn diretamente, que não pôde ser raspado por completo aqui) para checar as ~57 submissões não cobertas.
4. O diferencial defensável do FirstBite, se construído, é a **combinação pull-based + zero-balance genuíno + patrocínio de taxa automático em um fluxo de claim único e simples (QR/link)**, o que nenhuma submissão mapeada faz de forma integrada — mas isso é uma **inferência baseada em cobertura parcial**, não uma garantia de ineditismo.
